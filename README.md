* **Асинхронность (@EnableAsync):** На главном классе приложения `AmirbekovBelarysProjectApplication` включена поддержка асинхронного выполнения задач. В сервисе реализована фоновая симуляция отправки email-уведомлений при успешной регистрации пользователя.
* **Контейнеризация (Docker):** В корне проекта подготовлен `Dockerfile` с использованием многоэтапной сборки (**Multistage Build**: раздельные этапы `AS build` на базе Maven и финальный запуск на OpenJDK). В `docker-compose.yml` описан запуск приложения в связке с PostgreSQL и добавлена проверка доступности БД через `healthcheck`.
